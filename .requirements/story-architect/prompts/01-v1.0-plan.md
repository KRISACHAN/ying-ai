# v1.0 MVP 开发计划

基于 `requirements/architecture.md`，聚焦核心闭环：**一句话灵感 → AI 多轮对话引导 → 自动生成世界观/人物/大纲/章节内容**，删除所有非核心功能。

核心原则：优先跑通端到端流程，功能能用即可，不追求产品完整度。

---

## Stage 1: 基础框架 + 世界观 AI 闭环

**目标**: 搭建最小基础，打通核心 AI 技术链路：用户输入 → AI 流式回复 → Tool Calling 自动保存结构化数据 → 右侧展示结果。这是最核心的技术验证，完成后所有步骤复用这套模式。

**任务**:

1. **最小项目初始化**:
   - Next.js 16 + TypeScript + Tailwind v4 基础项目
   - Prisma schema 定义 + db push 建表
   - 连接本地 PostgreSQL（通过 `DATABASE_URL` 配置）
   - Prisma client 单例
2. **仅需基础 UI 组件**: Button, Input, Textarea
3. **极简首页**:
   - 只保留：灵感输入框 + 创建按钮 + 项目列表（仅标题，点击进入，不需要删除）
   - 只需要 2 个 API: POST 创建项目, GET 项目列表
4. **项目通用布局**:
   - 简单顶部标题 + 4 步进度指示器（不需要可点击回退，只显示当前进度）
   - 不需要标题编辑功能
5. **AI 核心链路打通**:
   - 配置 OpenAI 兼容客户端
   - 通用 ChatPanel: 消息列表 + 输入框 + 流式渲染
   - `/api/chat/[id]` 核心 API: 加载上下文、system prompt、streamText
   - 实现第一个工具 `updateWorld`，AI 调用后直接写入 WorldBuilding 表
   - 世界观 system prompt：引导用户对话，信息足够自动调用工具保存
6. **世界观页面**:
   - 左侧聊天，右侧简单文本展示四个字段（不需要点击编辑，只展示 AI 保存结果即可）
   - 底部一个「下一步」按钮，点击跳转到人物页，更新 currentStep

**验收标准**:

- 首页输入一句话灵感，点击创建成功进入世界观页面
- AI 能主动提问引导，回复流式输出
- AI 能主动调用 `updateWorld` 工具保存世界观数据到数据库
- 右侧能看到 AI 保存的世界观内容
- 点击「下一步」能跳转到人物页
- 刷新页面，世界观数据仍然存在

---

## Stage 2: 人物 + 大纲步骤

**目标**: 复用 Stage 1 已经打通的 AI 模式，快速完成人物和大纲两个阶段的数据生成。

**任务**:

1. **人物步骤**:
   - 添加 `addCharacter` 工具，AI 调用后保存人物到 Character 表
   - 人物 system prompt：基于灵感+世界观生成核心角色
   - 右侧简单列表展示人物卡片（展示姓名角色动机等，不需要编辑删除）
   - 人物页面 `/p/[id]/characters`，底部「下一步」跳大纲页
2. **大纲步骤**:
   - 添加 `batchCreateChapters` 工具，AI 调用后批量创建 Chapter 记录（number/title/summary）
   - 大纲 system prompt：生成扁平章节列表
   - 右侧简单列表展示章节标题和概要（不需要编辑）
   - 大纲页面 `/p/[id]/outline`，底部「下一步」跳章节页

**验收标准**:

- 人物步骤：AI 能自动生成角色，调用工具保存，右侧列表展示人物
- 大纲步骤：AI 能一次性生成多章大纲，批量保存到 Chapter 表，右侧展示章节列表
- 所有数据刷新后不丢失
- 可以线性走完：世界观 → 人物 → 大纲 → 进入章节页

---

## Stage 3: 章节生成 + 流程闭环

**目标**: 完成最后一步章节内容生成，跑通从灵感输入到生成小说章节的完整端到端闭环。

**任务**:

1. **章节页面**:
   - 左侧聊天，右侧章节列表，点击某章选中
   - 选中章节后用预格式化文本块展示 AI 生成的正文内容（只读展示，不需要编辑）
2. **AI 章节写作**:
   - 添加 `saveChapterContent` 工具
   - 章节 system prompt：携带世界观、人物、当前章节大纲上下文
   - 用户说「生成本章」，AI 流式生成内容并调用工具自动保存到 Chapter.content
3. **简单收尾**:
   - 基础错误提示（AI 调用失败提示重试）
   - 基础 loading 状态
   - 完整流程测试：从创建项目到生成第一章内容

**验收标准**:

- 进入章节页能看到大纲生成的章节列表
- 点击章节后，右侧展示该章已生成的正文内容（如果已有）
- 在聊天中要求 AI「生成本章初稿」，AI 流式生成内容，自动保存到数据库，并实时展示在右侧
- 完整端到端流程跑通：
  1. 首页输入灵感 → 创建项目
  2. 和 AI 对话构建世界观 → AI 自动保存
  3. AI 生成人物 → 保存展示
  4. AI 生成章节大纲 → 保存展示
  5. 选中章节 → AI 生成正文 → 保存展示
- 刷新页面所有数据不丢失
- 整个流程可以在 5-10 分钟内完成一部简单小说的初稿
