## 详细说明

### 功能保证

虽然 v1 可以不使用远程 tool call，langchain，langraph 等后期方案，但是仍然需要保证可以支持：

1. 个性设置（包含性别，就是「伴侣」角色可选男性、女性）
2. 记忆系统
3. 情绪状态机
4. 工具调用
5. 流程编排

### 插槽说明

完整的目标仍然是在未来某的一个版本把所有 AI Agent 需要用到的技术栈都接上。

并且接上的时候不会有破坏性改造，只需要修改某个接口/虚方法/插件等。

就如同 babel 的插件或 koajs 的中间件一般。

## 需求边界

你当下只聚焦于 v1 版本要做的事就可以，后续的我会在做完之后再出方案。

另外，当前我不需要单元测试与e2e测试，我只需要功能没有问题。

还有，前端 UI 也不是重点，当前这一版，前端 UI 只负责调试功能与后续正式的界面 UI 应该是两个应用。

这一版的 UI 也可以常驻，用以做功能调试。

这个 core 应该是要跟任何业务属性脱钩的，也不要接用户系统/鉴权什么的，这个是当前完成之后做的。

我需要的是一个干净纯粹，只有核心功能的 core / sdk。

## 未来展望

另外，这一版完成之后，我会做前后台的用户系统，也许还会有商业化，我希望后续接的时候也不要是破坏性的改造，而是直接接，并且用户与用户之间的「伴侣」不会互相干扰。
